📱 相機開不起來？ PLAN B

部分 Android 手機（如三星）即使授權相機，瀏覽器仍可能讀不到鏡頭。看到這個畫面時，請依下列步驟改用相簿：

  1. 先用手機原生相機 App 拍下身分證正反面（橫式拍攝）
  2. 回到報名頁面 → 看到「無法開啟相機」畫面 → 點 「🖼️ 從相簿選擇」
  3. 從相簿挑剛拍好的身分證照片即可，後續流程相同
⚠ 注意事項： 查無資料 → 確認字號沒打錯，仍查無請至櫃檯確認 ・ 送出成功後請務必加入訓練單位 LINE 官方帳號接收考試通知
